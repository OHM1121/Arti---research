# MA·마켓트렌드 개선안 2차 분석 — 검증 표본 확대 + 새 지표·점수체계

1차 분석(`APK_IMPROVE_README.md`)은 기존 조건의 수치만 바꿨고 검증 거래가 적었습니다. 이번에는 **표본을 크게 늘리고**, **새 지표와 점수체계**로 신호를 걸러 봤습니다.

## 1. 표본 확대

| 항목 | 1차 | 2차 |
|---|---|---|
| 코인 | 23개 | **45개** (SC, SHIB, STX, FIL, SAND, ALGO, AXS, WAVES, KAVA, VET, ELF, EGLD, LSK, ARK, GAS, CHZ, BAT, NEO, IOTA, IMX, GRT, ANKR 추가) |
| 일봉 이력 | 4년 | **최대 9년** (2017-11~) |
| 60분봉 이력 | 4년 | **6년** (2020-11~) |
| 30분봉 | 4년 | 4년 (코인 45개) |
| 5분봉 | 1년 | 1년 (23개 코인만) |
| 검증 방식 | 한 번의 분할 | **해마다 워크포워드**: 그 이전에 청산이 끝난 거래만으로 규칙을 고르고 그 해에 적용, 마지막 해는 최종 시험 |

**검증(out-of-sample) 거래 수** — 1차 대비 수십 배로 늘었습니다.

| | 5분 | 30분 | 60분 | 일봉 |
|---|---|---|---|---|

| 마켓트렌드 | 877 | 1,162 | 733 | 43* |

\* 마켓트렌드 일봉은 감시 10일로 45개 코인·9년을 봐도 후보가 43건뿐이라 워크포워드가 불가능합니다.

## 2. 방법

- 후보 거래 = 기본 규칙(APK 0.2.1, 슬리피지 0.05%, 손절 우선)이 낸 **모든 신호**. 필터는 그중 어떤 거래를 취할지만 정합니다.
- **새 지표 약 50개**: 모멘텀·수익률, 고점 대비 낙폭, 이평 이격·기울기, ATR·볼린저 폭, RSI(5/14/20)·스토캐스틱·CCI·MACD·ADX, 연속 하락 봉 수, 거래량 배수·z-score·OBV·MFI, 캔들 형태(몸통·꼬리·종가 위치), **BTC 시장 상태**(수익률·낙폭·RSI·MA120 이격·변동성), 시장점수와 그 변화, **전체 코인 중 상승·과매도·MA20 위 비율**(breadth), **전일 일봉 추세**(RSI·수익률·MA20/60 이격·ATR), BTC 대비 상대강도.
- **필터·점수체계 후보**: 단일 지표 규칙, 2지표 AND 규칙, 로지스틱 점수, 릿지 점수, 순위 합성 점수(상관 상위 6개 지표), 무작위 선택(잡음 기준선).
- 규칙을 고르는 **절차 전체**를 평가하므로, 많이 시험해서 얻은 우연이 결과에 섞이지 않습니다. numpy만 사용했습니다(scikit-learn 설치가 권한 정책으로 막혀 직접 구현).

## 5. 해석

1. **가장 신뢰할 만한 개선은 두 가지**입니다.
   - **MA 일봉 "BTC보다 뒤처진 코인의 반등만"**: 8개 연도 중 7개에서 플러스, 2026년에도 24건 승률 92%입니다.
   - **마켓트렌드 60분 "MA120보다 11% 이상 깊게 눌린 곳만"**: 2021~2026 모든 해에서 플러스입니다. 다만 최근 연도 거래가 적습니다(2025 8건, 2026 3건).
2. **약해지는 중인 개선**: MA 60분(깊은 과매도), MA 30분(BTC 모멘텀)은 2025~2026년에 평균이 0 근처 또는 음수로 내려왔습니다. 시장 국면 의존이 크다고 봅니다.
3. **마켓트렌드 30분의 BTC 변동성 규칙**은 거래의 70%가 2024년 한 해에 몰려 있어 일반화를 장담할 수 없습니다.
4. **5분봉은 거래 수천 건으로 확인해도 어떤 지표·점수로도 플러스가 되지 않습니다.** MA·마켓트렌드 5분은 개선 대상이 아니라 비활성화 대상으로 보입니다.
5. 새 지표 대부분이 **BTC 시장 상태**와 **더 긴 시간봉의 눌림 깊이**였습니다. 즉 "신호의 질"은 코인 자체의 단기 지표보다 시장 전체 상태와 눌림의 깊이에서 갈렸습니다.

## 7. 정책 확인 사항

- 3번·4번 표의 새 필터는 **시장점수를 쓰지 않으므로** 2026-11-20(#118) "시장점수는 기준봉만 막는다"와 충돌하지 않습니다. 다만 모두 **전략 규칙의 변경**이라 적용 여부는 사용자님이 정하셔야 하고, 저는 코드에 반영하지 않았습니다.
- 앱에서 구현하려면 일부 지표(전일 일봉 추세, BTC 상태, 전체 코인 breadth)는 기존에 없는 데이터 경로가 필요합니다.

## 8. 한계

- 4번 표의 임계값은 전체 이력에서 읽었습니다(안정성 점검용). 엄밀한 out-of-sample 수치는 3번 표입니다.
- 마켓트렌드 60분의 단일 지표 규칙은 검증 구간 마지막 해가 3건뿐입니다.
- 거래대금이 작은 코인(SC, GAS, ARK 등)은 실제 체결 슬리피지가 0.05%보다 클 수 있습니다.
- 시장점수는 근사치, 생존자 편향(현재 상장 코인 기준), 기본 12개 case(`apk_run.py`)는 여전히 23개 코인 기준입니다.
