# 연도별 지갑 수익률 (연도별로 끊어서, 전략·시간봉별)

## 계산 방식
- **해마다 지갑을 새로 시작**: 시간봉별 지갑 시드 200만원, 슬롯·종목당 금액은 지정 설정(5분·30분 10종목 20만/10만원, 60분 5종목 40만/20만원, 일봉 4종목 50만/25만원), 수수료 0.05% + 슬리피지 0.05%/편도, 손절 우선.
- 거래는 **진입한 해**에 귀속하고, 청산이 해를 넘겨도 끝까지 반영합니다. 해별 수익률 = (해당 해 지갑 최종 잔고 - 200만원) / 200만원.
- 괄호는 (거래 수 / 승률). **부분 연도**: 5분봉은 2025(11-21~12-31)와 2026(1-1~11-21), 30분봉 2022는 11-22부터, 60분봉 2020은 11-22부터, 2026은 모두 11-21까지입니다.
- 거래가 1~3건인 해는 수익률의 의미가 없습니다(표에서 건수를 확인하세요).
