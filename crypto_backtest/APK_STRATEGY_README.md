# APK(ARTITRADE 0.2.1) 코인 전략 3종 — 업비트 시간봉별 백테스트 (12개 case)

사용자의 APK 소스(`OHM1121/RESALE_ALPHA` **태그 0.2.1**)의 코인 전략 3개를 업비트 KRW 23개 코인 캔들에 **각각 따로**, 시간봉 4개(5분·30분·60분·일봉)로 적용했습니다.
규칙의 전체 내용은 저장소 루트 `CLAUDE.md`에 있습니다.

## 실행

```bash
python3 crypto_backtest/upbit_fetch_tf.py 1d 1h 30m 5m   # 23개 코인 수집 (1~2시간)
python3 crypto_backtest/apk_run.py                       # 12 case + 민감도, results/apk_*.csv 저장 (약 2분)
```

## 기본 설정 (사용자 지정)

| 항목 | 값 |
|---|---|
| 5분·30분봉 지갑 | 동시보유 **10종목**, 종목당 **20만원**(시장 좋을 때) / **10만원**(안 좋을 때) |
| 60분봉 지갑 | 동시보유 **5종목**, **40만원** / **20만원** |
| 일봉 지갑 | 동시보유 **4종목**, **50만원** / **25만원** |
| 시장 안 좋을 때 | 시장점수 ≤ -10 (기준봉은 점수 > 0일 때만 매수하므로 항상 "좋을 때") |
| 비용 | 수수료 0.05%/편도 + **슬리피지 0.05%/편도** (모든 체결에 적용: 매수 ×1.0005, 매도 ×0.9995) |
| 같은 봉에서 손절가·목표가가 모두 닿을 때 | **항상 손절 우선(패배 처리)** |
| 마켓트렌드 일봉 감시 | 24시간 → **5일** |

시간봉별로 독립 지갑이며 시드는 각각 200만원(슬롯 × 좋을 때 금액)입니다. **승률**은 거래 단위(분할매도 합산 후 순손익 > 0)입니다.
조회 기간: 5분봉 2025-11-21 ~ 2026-11-21(1년), 30분·60분봉 2022-11-22 ~ 2026-11-21, 일봉 2022-11-23 ~ 2026-11-21 (상장이 늦은 코인은 상장일부터).

## 해석

1. **손절 우선과 슬리피지를 넣자 기준봉 수익이 크게 줄었습니다.** 30분은 +11.5%(이전 방식) → +4.6%, 60분은 +6.3% → -2.1%, 일봉은 +17.0% → +8.2%입니다. 한 봉 안에서 목표가와 손절가가 함께 닿는 경우를 손절로 처리한 영향이 큽니다.
2. **기준봉은 30분봉과 일봉에서만 의미 있는 플러스**이고 60분은 손익분기 아래, 5분은 49건뿐입니다. 슬리피지 0.10%에서는 30분도 +0.5%로 거의 사라집니다.
3. **MA는 일봉만 플러스**(승률 76%, +30.2%)입니다. 5분~60분은 신호가 너무 자주 나와(5분 7,681건) 대부분 "직전 50봉 최저가 종가 이탈" 손절로 끝납니다. 슬롯 10개로 늘렸는데도 5분봉 신호 7,681건 중 4,684건은 슬롯이 차서 매수되지 못했습니다.
4. **마켓트렌드는 5분~60분 모두 손실**입니다. 일봉 감시를 5일로 바꾸니 0건 → 3건이 됐습니다(코드의 기울기 (-15,+20) 엄격 부등호에서는 5건). 일봉은 RSI 과매도 후 5일 안에 볼린저 중심선 위로 마감하는 경우 자체가 드뭅니다.
5. 모든 전략에서 슬리피지 0.05% → 0.10% 변화만으로 MA·마켓트렌드 수익률이 5~10%p 더 나빠집니다. 거래가 잦을수록 비용 민감도가 큽니다.

## 가정과 한계

- **슬리피지 0.05%/편도는 임의로 정한 기본값**입니다(업비트 알트코인 반스프레드 약 4~7bp 수준). 지정가 체결(기준봉 매수, 목표가 매도)에도 동일하게 적용해 보수적입니다. 값을 정해주시면 `apk_strategies.py`의 `SLIP`만 바꿔 다시 돌립니다.
- 슬리피지는 체결가에만 적용하고 트리거 가격(손절가·목표가)은 바꾸지 않았습니다.
- **엑셀 `NEW LEGACY(11.18)_rev1.xlsx`는 저장소에 없습니다.** 엑셀에만 있을 수 있는 수치는 APK 코드 값을 썼습니다.
- **시장점수는 재구성**했습니다(코드의 `coin_score` 공식을 23개 코인·24시간 롤링 등락률로 계산).
- **마켓트렌드 기울기는 사용자 지정값 -10° 이상 +20° 이하(경계 포함)**를 썼습니다. 코드는 (-15,+20) 엄격 부등호라 민감도에 같이 실었습니다.
- 봉 단위 근사: 틱·호가가 없어 한 봉 안에서는 하락 트리거를 항상 먼저 평가합니다. 호가 단위 반올림은 반영하지 않았습니다.
- 거래대금 TOP35/TOP50 필터는 유니버스가 23개라 항상 통과합니다. 5분봉은 1년(하락 구간 위주)이라 통계적으로 약합니다. 생존자 편향이 있습니다.
