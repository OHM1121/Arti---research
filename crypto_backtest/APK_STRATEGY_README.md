# APK(ARTITRADE 0.2.1) 코인 전략 3종 — 업비트 시간봉별 백테스트 (12개 case)

사용자의 APK 소스(`OHM1121/RESALE_ALPHA` **태그 0.2.1**)의 코인 전략 3개를 업비트 KRW 23개 코인 캔들에 **각각 따로**, 시간봉 4개(5분·30분·60분·일봉)로 적용했습니다.
APK도 세 전략을 독립 지갑으로 운용하므로 합치지 않았습니다. 규칙의 전체 내용은 저장소 루트 `CLAUDE.md`에 있습니다.

## 실행

```bash
python3 crypto_backtest/upbit_fetch_tf.py 1d 1h 30m 5m   # 23개 코인 수집 (1~2시간)
python3 crypto_backtest/apk_run.py                       # 12 case + 민감도, results/apk_*.csv 저장 (약 1분)
```

코드: `apk_strategies.py`(규칙·엔진), `apk_run.py`. 규칙마다 출처를 `[CODE]`(APK 코드)·`[POLICY]`(USER_ACTIVE_POLICY.md)·`[ASSUMED]`(가정)로 표시했습니다.

## 해석

1. **기준봉만 전 시간봉에서 플러스입니다.** 거래는 5분 49건, 30분 415건, 60분 162건, 일봉 47건입니다. 승률은 낮은 편(25~36%)이지만 이익이 손실보다 훨씬 커서(30분 평균 이익 +2.6% vs 손실 -0.6%) 손익비가 1.4~2.4입니다. 일봉만 승률 57%입니다.
2. **기준봉 거래 수가 늘어난 이유**: 앱 코드는 "목표가가 먼저 닿아도 후보·주문을 취소하지 않습니다"(FIX29). 이전 버전에서 제가 이를 취소하게 만들어 후보의 90%가 사라졌던 것이 원인입니다. 현재 30분봉은 후보 1,729개 중 415개가 체결됩니다(가격이 기준봉 저가로 돌아오지 않아 만료되는 비율이 약 62%).
3. **기준봉 청산의 대부분은 "진입가 복귀 전량매도"**(30분 259건, 평균 -0.11%)입니다. 이익은 TP1 이후 트레일링·방어선에서 나옵니다(30분 TP1 이후 구간 평균 +1.5~+4.6%).
4. **기준봉 일봉은 최근 약해졌습니다.** 2023년 승률 88%에서 2026년 20%(2026년 일봉 거래는 소수)입니다. 60분도 42% → 27%로 떨어졌습니다.
5. **MA는 일봉만 플러스**(승률 78%, +33.6%)이고 5분·30분·60분은 크게 손실입니다. 신호(MA120 하락 중 + 단기선 4개 상승 최초 전환)가 매우 자주 발생해(5분 7,681건) 대부분이 "직전 50봉 최저가 종가 이탈" 손절로 끝나고(평균 -1.7%~-4.8%), 이익은 작습니다. 슬롯이 4개뿐이라 신호의 상당수(5분 6,077건)는 지갑 규칙상 매수되지 않았습니다.
6. **마켓트렌드는 모든 시간봉에서 손실**이고 일봉은 신호가 0건입니다. 일봉에서는 RSI20 ≤ 30 뒤 "24시간 감시"가 다음 봉 하나뿐인데, 그 봉이 볼린저 중심선 위에서 마감하는 경우가 228번 중 1번뿐이었습니다.
7. **시장점수 필터를 끄면 기준봉이 오히려 좋아집니다**(30분 +36.1% → +72.6%). 다만 제가 재구성한 점수는 근사치라 실제 앱 점수의 효과로 단정할 수 없습니다.

## 가정과 한계

- **엑셀 `NEW LEGACY(11.18)_rev1.xlsx`는 저장소에 없습니다.** 엑셀에만 있을 수 있는 수치는 APK 코드 값을 썼습니다. 마켓트렌드 5분의 보유기간·트레일링은 가정값입니다.
- **마켓트렌드 기울기는 사용자 지정값 -10° 이상 +20° 이하(경계 포함)**를 썼습니다. 코드는 (-15,+20) 엄격 부등호라 위 민감도에 같이 실었습니다. 각도는 코드의 차트 투영각 식(높이 180px, 봉 간격 8px, 가격축 ±8% 여백)을 그대로 구현했습니다.
- **시장점수는 재구성**: 코드의 `coin_score` 공식을 쓰되 업비트 전체 KRW 마켓 대신 23개 코인과 24시간 롤링 등락률을 사용했습니다.
- **봉 단위 근사**: 틱·호가가 없어 한 봉 안의 순서를 양봉 O-L-H-C, 음봉 O-H-L-C로 가정했습니다. 호가 단위 반올림과 슬리피지는 반영하지 않았습니다. 특히 "진입가 복귀"처럼 가격 경로에 민감한 규칙은 실제와 다를 수 있습니다.
- **MA 진입**의 앱 방식(봉 마감 10~2초 전 형성 중 캔들 확인)은 신호봉 종가 체결로, **마켓트렌드 진입**은 신호봉 다음 봉 시가로 근사했습니다. 앱은 RSI를 형성 중 캔들로도 관측하므로 감시 시작 시점이 더 빠를 수 있습니다.
- 거래대금 TOP35/TOP50 필터는 유니버스가 23개라 항상 통과합니다. 앱은 더 많은 종목을 스캔하므로 후보 수가 더 많습니다.
- 5분봉은 1년(하락 구간 위주)이라 통계적으로 약합니다. 생존자 편향(현재 상장 코인 기준)이 있습니다.
