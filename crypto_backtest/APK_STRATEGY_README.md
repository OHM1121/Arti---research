# APK(ARTITRADE) 코인 전략 3종 — 업비트 시간봉별 백테스트

사용자의 APK 소스(`OHM1121/RESALE_ALPHA`)에서 코인 전략 3개의 규칙을 가져와, 업비트 KRW 23개 코인 캔들에 **각각 따로**, 시간봉별로 적용했습니다.
APK도 세 전략을 독립 지갑으로 운용하므로 합치지 않았습니다.

## 실행

```bash
python3 crypto_backtest/upbit_fetch_tf.py   # 23개 코인 5분/30분/1시간/일봉 수집
python3 crypto_backtest/apk_run.py          # 3개 전략 × 시간봉 실행, results/apk_*.csv 저장
```

코드: `apk_strategies.py`(규칙), `apk_run.py`(실행). 규칙마다 출처를 `[CODE]`(APK 코드), `[POLICY]`(USER_ACTIVE_POLICY.md), `[ASSUMED]`(저장소에 없어 가정)로 표시했습니다.

## 해석

1. **기준봉은 일봉에서만 의미 있는 수익**(+18.2%, 승률 63%)이 나왔지만 거래가 38건뿐입니다. 그중 36건이 점수 < -10 청산이라, 결과가 기준봉 자체보다 시장점수 규칙에 크게 좌우됩니다.
2. **기준봉 후보는 대부분 버려집니다.** 30분봉 808개 중 722개가 "매수 전 목표가 선도달"로 취소되고 21개만 체결됩니다. 거래 수가 적어 승률·수익률의 통계적 의미가 약합니다.
3. **시장점수 필터를 끄면 기준봉 수익이 오히려 좋아집니다**(30분 +12.6%, 60분 +12.0%). 다만 제가 재구성한 점수는 근사치라, 이것이 실제 앱 점수의 효과라고 단정할 수 없습니다.
4. **MA는 일봉을 제외하고 모두 손실**입니다. 승률 18~37%이고, 청산의 상당수(60분 480건 중 289건)가 진입봉 저가 이탈 규칙입니다.
5. **마켓트렌드는 30분·60분에서 크게 손실**입니다(승률은 45~49%지만 손익비 0.7). 청산의 63%가 "TP1 복귀"(60분 2,318건 중 1,462건)입니다. 목표가가 진입봉 고가라 진입가에 매우 가까운 구조에서, 분할매도 후 되돌림이 비용을 못 넘습니다.

## 가정과 한계 (중요)

- **NEW LEGACY(11.18).xlsx는 저장소에 없습니다.** 마켓트렌드 보유기간·TP 규칙, MA/마켓트렌드의 세부 수치는 엑셀에만 있을 수 있어, 가능한 범위에서 APK 코드(`[CODE]`)로 대체했습니다.
- **볼린저 기울기 (-20, +30)의 단위를 알 수 없어** SMA20의 1봉 변화율(bp)로 가정했습니다. 이 가정에서는 30분·60분에서는 거의 필터가 되지 않고, **일봉은 2건만 통과해 거래가 0건**입니다. 단위가 다르면 결과가 크게 달라집니다.
- **시장점수는 재구성**했습니다. 코드의 `coin_score` 공식을 그대로 쓰되, 업비트 전체 KRW 마켓 대신 23개 코인과 24시간 롤링 등락률을 사용했습니다.
- **거래대금 TOP50**은 유니버스가 23개라 항상 통과합니다. 실제 앱은 더 많은 종목을 스캔하므로 후보 수가 다릅니다.
- **봉 단위 근사**: 틱·호가 없이 OHLC로 체결을 판단합니다. 한 봉 안에서 손절과 익절이 모두 닿으면 손절을 우선했고, 호가 단위 반올림과 슬리피지는 반영하지 않았습니다.
- **MA 진입**의 앱 방식(봉 마감 10~2초 전 형성 중 캔들 확인)은 신호봉 종가 체결로 근사했습니다.
- 생존자 편향(현재 상장 코인), 5분봉은 90일(하락 구간 하나)뿐이라 통계적으로 약합니다.
