# 업비트 1분봉 백테스트

## 실행

```bash
python3 crypto_backtest/upbit_fetch_1m.py 180   # 업비트 공개 API, 180일치 1분봉 (코인당 약 6~8분, 총 약 30분)
python3 crypto_backtest/upbit_backtest_1m.py    # 백테스트 + 비용 민감도, results/upbit_1m_*.csv 저장
```

## 설정

- 데이터: 업비트 KRW 마켓 BTC, ETH, XRP, SOL, DOGE. 2026-05-25 ~ 2026-11-21, 코인당 약 259,000봉.
  무거래 분은 응답에 없어 직전 종가로 채움 (BTC 0.4%, SOL 2.4%, DOGE 11.3%).
- 체결: 봉 종가에서 신호 계산, **다음 봉 시가**에 체결. 롱 온리, 코인당 전액 투입.
- 비용(편도): 수수료 0.05% + 슬리피지 0.03% = 0.08%.
- 전략(파라미터 사전 고정, 튜닝 없음): EMA20/60 교차, 돈치안(60 돌파·20 이탈), RSI14<25 진입·>50 청산, 볼린저(20,2) 하단 진입·중심선 청산. 역추세는 60분 시간 청산.

## 결과 (편도 0.08%, 전체 기간)

| 전략 | BTC | ETH | XRP | SOL | DOGE |
|---|---|---|---|---|---|
| EMA 교차 | -98.7% | -99.3% | -99.1% | -99.4% | -100% |
| 돈치안 | -91.8% | -93.0% | -91.0% | -91.0% | -87.4% |
| RSI 역추세 | -86.4% | -54.5% | -53.4% | -37.0% | **+50.4%** |
| 볼린저 역추세 | -99.96% | -99.9% | -99.9% | -99.9% | **+13,160%** |
| 매수후보유 | -31.0% | -28.5% | -39.3% | -26.8% | -52.2% |

## 해석

1. **BTC·ETH·XRP·SOL은 모든 전략이 손실입니다.** 거래가 수천 건이라 편도 0.08%가 누적되면 계좌가 소멸합니다.
   비용 0 가정에서는 RSI·볼린저 역추세가 중앙값 기준 +31~39%지만 수수료 0.05%만 넣어도 사라집니다
   (`results/upbit_1m_cost_sensitivity.csv`).
2. **DOGE의 +13,160%는 신뢰하면 안 됩니다.** 다른 4개 코인이 모두 -99.9%인데 DOGE만 극단적이라 따로 점검했습니다.
   - 가격이 약 113원이라 호가 단위가 상대적으로 크고, 1분봉의 64%가 무변동입니다.
   - 종가·시가는 매수/매도 호가 사이를 오가는 체결가라, 이를 "시가에 체결"로 가정하면 스프레드가 수익으로 잡힙니다.
   - 비용을 올리면 즉시 무너집니다: 편도 0.10% +2,720%, 0.12% +443%, **0.15% -34%, 0.20% -98%**.
   - 조회 시점 실제 스프레드는 BTC 2bp, ETH 13bp, XRP 8bp, SOL 11bp, DOGE 14bp였습니다(1회 스냅샷).
     즉 DOGE 편도 비용은 수수료 0.05% + 반스프레드 약 0.07% = 약 0.12%에 시장 충격까지 더해지므로, 손익분기 근처에서 불안정한 구간입니다.
   - DOGE 결과는 실거래 가능한 우위가 아니라 체결가 가정의 산물로 보는 것이 안전합니다.
3. 알트코인(ETH·XRP·SOL)은 실제 반스프레드(4~7bp)가 가정한 슬리피지(3bp)보다 커서, 기본 비용도 다소 낙관적입니다.
