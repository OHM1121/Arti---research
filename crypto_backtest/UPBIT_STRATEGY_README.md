# 원래 전략(README 규칙)을 업비트 타임프레임별로 적용

> **참고**: 이 문서는 `crypto_backtest/README.md`(Binance 일봉 연구)의 규칙을 업비트에 적용한 결과입니다. 사용자의 APK 전략(기준봉·MA·마켓트렌드)을 적용한 결과는 `APK_STRATEGY_README.md`를 보세요.

`backtest.py`의 규칙을 그대로 업비트 KRW 마켓 5개 타임프레임(1분·5분·30분·1시간·일봉)에 적용했습니다.
시장 필터(BTC > 200선), 종목 점수 5개 조건(MA20/60/120 정배열 포함), 거래대금 급증 돌파 또는 20선 눌림 진입,
ATR 손절, 20선 2봉 이탈 청산, 주간 점수 갱신은 원래 그대로입니다. 새 전략을 만들거나 튜닝하지 않았습니다.

## 실행

```bash
python3 crypto_backtest/upbit_fetch_tf.py     # 23개 코인 캔들 수집 (약 20분, 호출 제한 때문)
python3 crypto_backtest/upbit_strategy_tf.py  # 전 타임프레임 백테스트, results/upbit_strategy_*.csv 저장
```

## 적용 방식

- **봉 개수 환산**: 모든 기간을 봉 개수로 유지했습니다. 1봉이 "하루" 역할입니다.
  BTC 200봉선, MA20/60/120, ATR14, 20봉 고가 돌파, 365봉 모멘텀·고점, 126봉 상대강도, 7봉마다 "주간" 갱신.
  일봉은 원래대로 일요일 종가 갱신입니다.
- **유니버스**: 업비트 KRW 23개 코인(BTC, ETH, XRP, SOL, DOGE, ADA, AVAX, LINK, DOT, TRX, XLM, ATOM, ETC, BCH, NEAR, AAVE, UNI, SUI, APT, ARB, OP, HBAR, POL).
  종목 간 모멘텀 순위(상위 20%)를 쓰는 전략이라 5개 코인으로는 의미가 없어 넓혔습니다. 생존자 편향이 있습니다.
- **기준봉**: README에 정의가 없어, 진입의 돌파봉(직전 20봉 고가 돌파 + 거래대금 20봉 평균 1.5배)을 기준봉으로 보았습니다.
  다른 정의라면 알려주세요.
- **비용**: 편도 수수료 0.05% + 슬리피지 0.05% (원래 연구는 0.1% + 0.1%). 펀딩비 필터는 데이터가 없어 제외.
- **기간**: 타임프레임마다 다릅니다. 지표 워밍업(365봉) 이후부터 집계합니다.

| 타임프레임 | 수집 기간 | 집계 구간 |
|---|---|---|
| 일봉 | 4년 | 2023-11 ~ 2026-11 |
| 1시간 | 4년 | 2022-12 ~ 2026-11 |
| 30분 | 2년 상당(데이터 4년분 확보) | 2022-11 ~ 2026-11 |
| 5분 | 90일 | 2026-08 ~ 2026-11 |
| 1분 | 30일 | 2026-10 ~ 2026-11 |

1분·5분봉은 기간이 짧아 통계적으로 약합니다. 1분봉을 23개 코인으로 길게 받으면 몇 시간이 걸려 줄였습니다.

## 해석

1. **어느 타임프레임에서도 비용 후 수익이 없습니다.** 일봉은 비용 0으로 해도 손실(-2.9%)이라 비용 문제가 아니라 규칙 자체의 엣지가 약합니다.
   바이낸스 일봉 연구(-2.8%, 승률 28%, 투자비중 3%)와 같은 모습입니다.
2. **비용 0에서 플러스인 것은 1시간(+36.7%, 손익비 1.13)과 30분(+13.4%, 1.07)뿐입니다.** 거래가 2,300~2,500건이라
   편도 0.10%가 누적되면 사라집니다. 엣지가 있어도 비용보다 얇습니다.
3. **1시간·30분의 연도별 안정성이 없습니다.** 1시간은 2024·2025년 소폭 수익(약 +5%, +4%), 2023년 약 -21%, 2026년 약 -3%
   (거래 손익 합계 기준). 최대낙폭 -42%는 2023-01 고점 10,872에서 2024-10 저점 6,288까지 2년에 걸친 것입니다.
4. **5분·1분봉은 크게 손실입니다.** 손절폭(2×ATR)이 비용(왕복 0.2%)보다 작아, 1분봉은 청산 1,700여건 중 갭 손절 816건이고
   모든 청산 유형의 평균 수익이 -0.3% 안팎입니다. 비용 0에서도 손실이라 규칙이 이 타임프레임에 맞지 않습니다.
5. **시장 필터는 효과가 있습니다.** 일봉을 제외한 모든 타임프레임에서 필터를 끄면 손실이 커집니다
   (1시간 -13.6% → -24.2%, 5분 -43.6% → -54.1%).
6. 일봉·1시간·30분에서 BTC 보유(+58%, +255%, +249%)에 크게 뒤집니다. 평균 투자비중이 3~7%라 대부분 현금이기 때문입니다.
   1·5분 구간은 BTC가 -26%로 하락했는데 전략은 이보다 더 잃었습니다.

## 한계

- 타임프레임별 기간과 시장 국면이 달라 서로를 직접 비교하기 어렵습니다. 특히 1분·5분은 하락 구간 하나뿐입니다.
- 봉 개수 환산은 하나의 해석입니다. 시간 기준 환산(예: 1시간봉 200일선 = 4,800봉)은 짧은 타임프레임에서 데이터가 부족해 불가능합니다.
- 업비트 호가 스프레드는 한 시점 스냅샷만 확인했고, 시장 충격은 모델링하지 못했습니다.
- 생존자 편향(현재 상장 코인 기준)으로 결과가 실제보다 좋게 나옵니다.
