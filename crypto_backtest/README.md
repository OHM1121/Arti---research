# 코인 추세추종 규칙 백테스트

이 폴더는 `주식·코인 상승추세 지속 종목 매매법` 규칙을 Binance USDT 현물 일봉 데이터로 검증한 코드입니다.
규칙은 설계 당시 정한 그대로 두었고, 결과는 조정 없이 그대로 기록했습니다.

## 실행 방법

```bash
python3 crypto_backtest/fetch_data.py   # data.binance.vision 에서 일봉·펀딩비 다운로드 (약 4분)
python3 crypto_backtest/backtest.py     # 백테스트 실행, results/ 에 결과 저장
```

필요 패키지: `pandas`, `numpy`, `requests`

## 데이터

- 출처: `https://data.binance.vision` (공개 데이터, API 키 불필요)
- 기간: 2019-09-01 ~ 2026-10-31 (UTC 일봉)
- 종목 25개: BTC, ETH, BNB, XRP, ADA, DOGE, LTC, TRX, LINK, XLM, ETC, BCH, DOT, UNI, ATOM, FIL, NEAR, SOL, AVAX, MATIC, APT, ARB, OP, SUI, AAVE
- 펀딩비: USDT-M 선물 펀딩비를 일별로 합산해 사용

**생존자 편향(survivorship bias)**: 종목 목록을 현재 시점에서 유동성 있는 코인으로 골랐습니다. 과거에 상장폐지되었거나 순위에서 밀려난 코인이 빠져 있어 **모든 결과가 실제보다 좋게 나옵니다.** MATIC은 2024-09 이후 데이터가 끊겨 있어(POL로 개명) 해당 시점에 보유 중이면 마지막 가격에서 청산됩니다.

## 규칙 (원문 그대로)

| 단계 | 규칙 |
|---|---|
| 시장 필터 | BTC 종가 > BTC 200일선이면 신규 진입 허용, 아니면 신규 진입 없음 |
| 종목 점수 (매주 일요일 종가) | A 12-1개월 모멘텀 상위 20% / B 52주 고가의 90% 이상 / C 정배열(종가>20>60>120일선) / D 20일 평균거래대금 ÷ 120일 평균 ≥ 1.2 / E 6개월 수익률 > BTC. **4개 이상** 충족 후 점수순·모멘텀순 상위 10개 후보 |
| 진입 조건 (후보 종목, 일별 종가 기준) | 돌파: 종가 > 직전 20일 고가 AND 거래대금 ≥ 20일 평균 × 1.5, 또는 눌림: 저가가 20일선 +1% 이내 터치 후 20일선 위에서 양봉 마감 AND 거래대금 증가. 펀딩비 필터: 8시간 평균 펀딩비 ≤ 0.1% (데이터 없으면 통과) |
| 체결 | 신호 다음 날 시가 |
| 포지션 크기 | 자본의 1%를 리스크로, 손절폭 = 2 × ATR14. 종목당 최대 10%, 전체 투자 최대 60%, 최대 10종목 |
| 손절 | 초기 손절 = 진입가 − 2 ATR14, 추적 손절 = 진입 후 최고 고가 − 3 ATR14 (둘 중 높은 값) |
| 청산 | 종가가 20일선 아래 2일 연속 마감, 또는 주간 점수 3 미만 |
| 비용 | 수수료 0.1% + 슬리피지 0.1% (편도) |

**구간별 (규칙 그대로)**: 2020-09~2022-12 +24.8% (샤프 1.02) → 2023~2026-10 −22.1% (샤프 −0.85)
**구간별 (탐색용 min_score=3)**: 2020-09~2022-12 +80.1% → 2023~2026-10 +1.6%

### 해석

1. **규칙 그대로는 엣지가 없습니다.** 비용을 빼기 전(gross) 손익비가 1.00, 총수익 0%입니다. 수수료·슬리피지를 넣으면 손실로 바뀝니다.
2. **진입 조건이 너무 드뭅니다.** 점수 4 이상은 전체 종목·일의 약 3%에서만 발생하고, 평균 투자비중이 3%라 대부분 현금입니다. 그래서 상승장에서 보유 전략보다 크게 뒤처집니다.
3. **구간 안정성이 없습니다.** 2020~2022 구간에서 나타난 수익이 2023년 이후 사라졌습니다. 탐색용 완화 조건(min_score=3)도 OOS가 +1.6%에 그쳤습니다.
4. **위험 감소 효과는 있습니다.** 탐색용 전략의 최대낙폭(−22%)은 BTC(−77%)보다 훨씬 작습니다. 다만 이는 대부분 현금 비중 때문이며, 수익률 대비 대가가 큽니다.
5. 탐색용 변형은 원래 규칙에 없던 기준을 **결과를 보고** 바꾼 것이라 과최적화 가능성이 있습니다. 참고 자료로만 보세요.

## 검증 확인

- 회계 검증: 최종 자산 = 초기 자본 + 전체 거래 손익 합계 (오차 0). 종료 시점 보유 포지션 없음.
- 가격 데이터 검증: 고가 < 저가 또는 종가가 범위를 벗어난 행 없음.
- 극단값: DOGE 2021-01-28 +392% 일일 상승은 실제 시장 움직임으로 확인됨(데이터 오류 아님). 이 날을 뺀 동일가중 2021년 수익률은 +741%입니다.

## 한계

- 생존자 편향 (위 참고)
- 일봉 기준이라 장중 손절 체결이 실제와 다를 수 있음 (갭은 시가로 처리, 그 외는 손절가로 가정)
- 펀딩비 필터는 선물 데이터 기준이지만 체결은 현물 가정
- 슬리피지 0.1%는 대형 코인 기준. 중소형 코인은 더 큽니다.
- 과거 결과가 미래 수익을 보장하지 않습니다.

## 파라미터 탐색 (손익비 PF ≥ 1.01 조합)

`search.py`: 2,592개 조합을 2020-09~2022-12(IS)에서만 탐색했습니다. `walkforward.py`: 과거 데이터로만 고른 조합을 다음 구간에 적용했습니다.

- IS에서 PF ≥ 1.01이고 거래 30회 이상인 조합: 1,400개
- 그중 OOS(2023~2026-10)에서도 PF ≥ 1.01: 571개 (IS+OOS 모두 거래 50회 이상이면 315개)
- 전체 조합의 OOS PF 중앙값은 0.76이며, PF ≥ 1.01 기준은 손익분기에 가까운 낮은 기준입니다.
